# Agent 做企业四维度分析：商业模式｜管理层作为｜资本回报｜股价安全边际

> 
> 四个模块，对应卖方分析师的经典分析框架。
> 整体思路：**用 LangGraph 构建多子 Agent（分工）+ Supervisor 主管调度，接入外部数据源工具（yfinance、SEC‑EDGAR、FRED、AlphaVantage），每个子 Agent 负责一个分析维度；最后汇总输出完整分析报告。**

> 
> 四个分析维度：

1. **商业模式**：赚钱方式、逐年经营历史、相对同行的优势
2. **管理层作为**：战略选择、资本配置、股权激励、高管履历、管理层诚信、收购 / 回购 / 分红决策
3. **资本回报**：ROE、ROIC、投入资本回报，资本效率，自由现金流，资本开支
4. **股价安全边际**：估值、可比公司、DCF、悲观 / 基准 / 乐观情景、下行风险、安全边际空间

## 整体架构（LangGraph Supervisor 多智能体）

```
START → Supervisor主管Agent
    ↓条件路由
├─ Agent‑1【商业模式分析师】 → 调用工具：SEC年报10‑K、行业新闻
├─ Agent‑2【管理层分析师】 → 调用工具：SEC代理声明DEF14A（高管薪酬、股权激励）、财报管理层讨论MD&A
├─ Agent‑3【资本回报分析师】 → 调用工具：AlphaVantage / yfinance / EDGAR财报，计算ROIC、ROE、FCF
├─ Agent‑4【安全边际估值分析师】 → 调用工具：可比公司数据、宏观FRED数据，DCF、敏感性分析
↓
汇总Agent：把四份子报告合并，做交叉校验，标记数据来源与预测/真实数据
↓ END输出最终完整分析
```

- **全局 State**：保存标的股票代码、公司名称、原始财报文本、4 个子模块输出结果、数据来源列表、风险标记。

```
class CompanyAnalysisState(TypedDict):
    ticker: str  # 股票代码，如 GOOGL
    company_name: str
    sec_10k_text: str   # EDGAR拉取10‑K年报文本
    def14a_text: str    # 管理层代理声明
    business_model_report: str
    management_report: str
    capital_return_report: str
    margin_of_safety_report: str
    final_report: str
    source_note: Annotated[list, operator.add] #记录每一条结论的数据来源
```

> 
> 关键点：**每个子 Agent 内部是 ReAct 循环**：思考 →调用工具拉取财报 / 行情数据 →Observation 拿到原始数据 →推理输出分析。

# 每个子 Agent：任务目标、需要调用的工具、关键指标、Prompt 要点

## 1）Agent‑1：商业模式分析 Agent

### 数据源工具调用

1. SEC‑EDGAR 10‑K 年报，Item1（Business 章节）：官方描述业务板块、收入拆分、竞争对手、供应链
2. 新闻工具：获取近期业务动态、新产品、行业格局

### 需要输出内容

1. **赚钱方式**：收入从哪来、怎么收——产品/服务构成与主营占比、客户是谁、收费模式（一次性销售 / 订阅 / 许可 / 按量 / 广告 / 佣金）、定价权来自什么、为什么形成现在这个毛利结构
2. **经营历史**：从创立到现在逐年看——材料里每一年的年报与年度数据都要用到，讲清收入与利润的走向、主营构成与战略重心的变化、转折点出现在哪一年、因为什么。材料只覆盖到哪一年就写到哪一年，未覆盖的年份列入 data_gaps，不得外推
3. **相对同行的优势**：把竞争位置与同行横向比——优势具体体现在哪（成本、品牌、渠道、技术、牌照、规模、客户粘性）、靠什么撑住、有没有在被收窄。材料没有可比公司数据时只做结构性归因，并把缺口写明

> 
> Prompt 重点：
> “**只使用 10‑K 年报和新闻工具返回的原文证据，每一条分析要标注来源，禁止幻觉编造业务事实**。区分事实陈述和主观推断。”

## 2）Agent‑2：管理层作为分析 Agent

> 
> 最重要文档不是 10‑K，是 **DEF14A 代理声明文件（SEC EDGAR）**，还有财报中 MD&A 管理层讨论部分

### 数据源工具调用

1. SEC EDGAR `DEF 14A`：高管履历、高管薪酬结构（基本工资、奖金、股权激励占比）
2. 10‑K MD&A 章节：管理层对经营的解释
3. 工具读取：回购、分红、大额收购、资产剥离公告

### 分析维度

1. **高管团队背景**：CEO/CFO 任职年限，过往业绩
2. **薪酬机制**：薪酬多大比例和业绩挂钩；是否存在高薪但业绩不达标
3. **资本配置行为（核心！）**
   - 分红、股票回购：什么价位回购？高价回购还是低位回购
   - 并购：收购标的价格，收购之后业绩是否兑现，是否大额商誉减值
   - 再投资：资本开支投向，是投入核心主业还是盲目多元化
4. 管理层诚信：是否频繁会计调整、关联交易风险
5. 风险：管理层过度乐观、盲目扩张

> 
> Prompt 约束：
> “不要简单做道德评判，全部基于文件中客观行为证据；例如：‘公司在股价高位大规模回购’，而不是‘管理层很糟糕’。”

## 3）Agent‑3：资本回报分析 Agent（定量为主）

### 数据源

SEC‑EDGAR 财报 XBRL 结构化数据，yfinance，AlphaVantage

### 核心计算指标（Agent 要调用代码工具计算）

1. **ROE 净资产收益率，拆分杜邦分析**：销售净利率、资产周转率、权益乘数
2. **ROIC 投入资本回报率（最重要，剔除杠杆干扰）**

\(ROIC=\frac{NOPAT}{投入资本}\)

> 
> NOPAT 税后净营业利润，投入资本 = 权益 + 有息负债‑现金

3. 自由现金流 FCF，FCF / 净利润比率（看利润是不是真金白银）
4. 资本开支占收入比重，资本开支是维持性还是扩张性
5. 历史 5‑10 年上述指标变化趋势

### 输出分析内容

1. 资本回报历史趋势：ROIC 是否长期高于 WACC（加权平均资本成本），判断企业是否创造价值
2. 利润质量：净利润和自由现金流是否匹配，是否存在大量应收
3. 资本使用效率：赚来的钱如何分配：再投资、分红、回购、并购、存现金
4. 风险：ROIC 持续下行，资本回报率低于融资成本，说明企业毁灭股东价值

> 
> 注意：Agent 必须区分**历史真实数据 vs 预测数据，记录计算公式，避免 AI 幻觉算错财务指标。**

## 4）Agent‑4：股价安全边际（估值分析）

### 数据源

1. 公司历史财务数据、可比上市公司财务与估值（yfinance / AlphaVantage）
2. FRED 宏观数据：无风险利率，用于 WACC 计算

### 分析内容

1. **相对估值**：PE、PB、EV/EBITDA，和自身历史分位对比，和同行业可比公司对比
2. **绝对估值 DCF 现金流折现**：基准情景，悲观情景，乐观情景三套假设
3. 计算内在价值区间，当前股价相对内在价值的折扣 = **安全边际**
4. 敏感性分析：WACC 变化、永续增长率变化，如何改变内在价值
5. 下行风险：什么条件下安全边际消失，最大下行空间

> 
> Prompt 强制约束：
> “明确给出悲观、基准、乐观三种情景；安全边际不是一个单点数字，是区间；清晰列出全部假设条件。不要只输出单一目标价。”

## 5. 汇总校验 Agent（非常关键，对抗 AI 幻觉）

接收 4 份子报告，做两件事：

1. **交叉校验**：不同 Agent 的结论是否冲突。例如商业模式 Agent 说毛利率会提升，资本回报模块要检查 ROIC 是否匹配这个结论；冲突则标记风险。
2. **来源标记**：每一条结论标注来自 10‑K / DEF14A / 市场数据 / AI 预测。**区分【真实历史数据】和【模型预测】**，就像你前面 GOOGL 那份 FinRobot 报告的校验逻辑。
3. 生成最终完整报告。
